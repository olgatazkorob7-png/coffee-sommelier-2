# ☕ Кофейный сомелье (Coffee Sommelier)

AI-ассистент для интернет-магазина обжарщика кофе. Учебный проект (Домашнее задание Pro по теме «Деплой и финализация»).

Ассистент помогает клиентам подобрать сорт кофе под вкусовые предпочтения, выбрать правильный помол, настроить подписку, а также отвечает на вопросы о хранении, доставке и оплате.

## 🚀 Особенности реализации
*   **Три зоны интерфейса:** список категорий, окно диалога, карточка рекомендуемого товара.
*   **Динамическая база знаний:** Приложение при каждом запросе подтягивает актуальную базу знаний и каталог из Google Sheets через Google Apps Script. Изменения в таблице применяются без пересборки проекта.
*   **Асинхронное логирование:** Каждый вопрос пользователя (и классификация ответа) отправляется в отдельный лист Google Sheets, не блокируя ответ ассистента.
*   **Безопасность:** Ограничения на медицинские рекомендации, политику и раскрытие системного промпта.

## 🛠 Технологический стек
*   **Фреймворк:** Next.js 15 (App Router), React, TypeScript
*   **Стилизация:** Tailwind CSS, Lucide Icons
*   **AI-модель:** Google Gemini API
*   **Источник данных и логирование:** Google Sheets + Google Apps Script

## 📂 Структура проекта
*   `app/api/chat/route.ts` — API-роут для общения с Gemini и логирования.
*   `components/CoffeeSommelierApp.tsx` — Основной UI-компонент (три зоны).
*   `lib/coffee-data.ts` — Сборка системного промпта, типы данных.
*   `server/loggerService.ts` — Модуль отправки логов в Apps Script.
